child psychology expert, UI/UX designer, and senior React.js developer.
Your mission is NOT to create a website. Your mission is to create a high-converting sales page
that convinces parents to purchase an annual subscription of VidhyaVibe.
The page must convert cold traffic from Facebook Ads, Instagram Reels, Google Search, and

breakpoint. Every layout, spacing, and CTA decision should be validated at 375px width first.

The page should feel premium like Apple, emotionally persuasive like Disney, and conversionfocused

Positioning
Never sell a magazine. Sell transformation, the child’s future, confidence, curiosity, intelligence,
practical learning, future readiness.
Visual/Content Safety Rules
Imagery: Use only illustrations, iconography, and abstract/graphic representations of
children and families. Do NOT use real photographs of identifiable minors anywhere on the
page.
Social proof: No real testimonials, ratings, or subscriber counts exist yet. Use clearly labeled
placeholder blocks, e.g. [TESTIMONIAL PLACEHOLDER — PARENT NAME, CITY] , [INSERT SUBSCRIBER COUNT] ,
[INSERT SCHOOL PARTNER LOGOS] . Never invent fake numbers, names, or quotes to fill these
sections.
FAQs: Write realistic, genuinely useful FAQ questions (e.g., delivery format, refunds, renewal,
content depth per age group) but flag any answer that depends on real policy with [CONFIRM
POLICY] rather than inventing one.
Configurable Flags (decide later, build both states now)
Build the component so these can be toggled via a single config object/prop — don’t hardcode
either state into the copy:
If urgencyType = "real-deadline" : show a live countdown timer tied to an actual end date/time.
If urgencyType = "evergreen" : show a standing “Founding Batch Pricing” or “Limited Seats This
Month” framing with no fake timer (avoids dark-pattern/legal risk).
If autoRenew = true : checkout and CTA copy must disclose “renews automatically each year,
cancel anytime” near the price.
If autoRenew = false : copy should say “one-time annual payment, no auto-charge.”
Payment & Tracking
Payment gateway: Razorpay (already registered). Checkout component should be built
assuming Razorpay Checkout.js integration — order creation → Razorpay modal →
success/failure redirect states. Include UI states for: processing, success, failure/retry.
Analytics/tracking hooks: Include event-tracking placeholders in the component structure
for Facebook Pixel and GA4 — specifically: PageView , ViewContent (age group card seen),
const offerConfig = {
urgencyType: "evergreen", // "real-deadline" | "evergreen"
autoRenew: false, // true | false — affects CTA microcopy & checkout disclosure text
}
AddToCart (age group selected), InitiateCheckout , Purchase . Structure these as clearly
commented hook points so a developer can wire in real IDs later.
Trust & Safety Signals (add to page)
Money-back guarantee badge (copy: [CONFIRM REFUND POLICY] placeholder if not decided)
Payment security badges (Razorpay trust badge, SSL/secure checkout iconography)
Data privacy line near checkout: reassure parents that child’s data is protected (no real policy

Auto-renewal disclosure per the flag above
